# ADR-001：技术栈选型

> 架构决策记录（ADR）。本文件是 explore 头脑风暴的结论固化，作为后续 spec/plan 的技术基线。

| 项 | 值 |
|----|----|
| 状态 | 已接受（2026-08-28，项目所有者评审通过） |
| 日期 | 2026-08-21 |
| 关联 | `docs/constitution.md`、`docs/roadmap.md` |

---

## 背景

farm-manage-system 是农场管理 SaaS：前端优先、多租户、云部署、从零新建。
经 OpenSpec explore 多轮讨论，确定以下技术栈。其中「已确认」为拍板项，「倾向」为推荐值、以首期 spec 最终落定为准。

---

## 决策

### 已确认

| 层 | 决策 | 说明 |
|----|------|------|
| 前端框架 | Vue 3 + TypeScript + Vite | 基线已定 |
| UI 库 | Element Plus（倾向，见下） | 管理后台/表格/表单成熟 |
| 状态/路由 | Pinia + Vue Router | 官方默认 |
| 后端框架 | Java + Spring Boot 3.x + JDK 21 | 「最主流」方向 |
| 数据库 | MySQL 8 | 单库，含地块 GEOMETRY/GeoJSON |
| 多租户 | 单库 + `tenant_id` 列隔离 | 框架级拦截 |
| 部署 | 云 SaaS，模块化单体 | 非微服务 |
| 地图 | 客户端 Leaflet（2D）+ Cesium/MapLibre（3D）；**不用高德** | 几何计算全在客户端（Turf.js 点面判断） |
| 地块存储 | MySQL `GEOMETRY/GeoJSON`；面积由前端地图 SDK 计算，update 轮廓触发重算；服务端校验多边形合法性（JTS） | 不上 PostGIS |
| 农事模型 | 作业单 + 明细（主从），支持批量 | 单条快捷记录 = 一主一从 |
| 渲染服务 | 独立 Node 服务（Playwright/Puppeteer），HTML/CSS → 图片 | 承接合格证渲染 |
| 合格证 | 一证一码；二维码 PNG；二维码溯源（公开溯源页） | 整证渲染产物 PNG（已确认） |
| 合格证模板 | HTML/CSS 由客户端提交维护；字段独立成表、每模板关联不同字段；模板表含纸张宽/高(mm)+彩色标记 | 动态字段 |
| 合格证模板编辑器 | 可视化拖拽设计器，DOM 绝对定位方案（输出 HTML/CSS，与渲染服务同源） | fabric.js canvas 方案排除 |
| AI Agent 框架 | Spring AI（主干）+ LangChain4j（备选） | 见下 |
| 大模型 | OpenAI 兼容接口 + 国产模型（DeepSeek/通义/GLM） | 抽象 Provider 层可切换 |
| 向量库 | Qdrant（初期）/ Milvus（规模化） | 双层知识库 RAG，按 tenant 过滤 |
| AI 工具协议 | Function Calling + MCP | 农事/合格证/库存封装为工具 |
| 设备接入 | 对接第三方系统（非硬件直连）：农场→物联网基地表、OAuth2/AppKey 授权、服务端代理转发、客户端渲染+控制设备 | 符合宪法「仅做数据接入」边界 |

### 倾向 -> 已由 [ADR-002](ADR-002-核心选型固化.md) 全部确认

| 决策点 | 倾向 | 备选 | 理由 |
|--------|------|------|------|
| 持久层 | **MyBatis-Plus** | Spring Data JPA | 复杂报表/打印取数手写 SQL 友好，中文生态主流 |
| 鉴权 | **Sa-Token** | Spring Security + JWT | 轻量、RBAC 开箱即用、中文文档好 |
| UI 库 | **Element Plus** | Naive UI / Ant Design Vue | 管理后台最主流 |

## 后果与待跟进

1. **宪法张力（时间类型）**：`constitution.md` 3.2 写「统一 UTC 存储（`timestamptz`）」——`timestamptz` 是 PostgreSQL 类型，与 MySQL 选型冲突。需走 `docs/changes/` 提案将数据原则修订为 MySQL 等价实现（`DATETIME` 存 UTC）。✅ 已解决：宪法 v1.2（提案 `20260827-宪法数据边界修订`）。
2. **宪法后端占位**：`constitution.md` 2.2「后端：待定」已被本 ADR 落为 Java/Spring Boot，建议提案同步。✅ 已解决：宪法 v1.2。
3. **术语表补充**：种植计划、物联网基地、设备、合格证、物候期、知识库、传感器、农机等新术语，按宪法流程在对应 spec 中登记后回填宪法。✅ 已解决：宪法 v1.2 术语表已补 10 词（现 16 词）。
4. **新增外部依赖**：AI Agent 引入 LLM + 向量库，按宪法 2.4「外部依赖接口化」，需做 Provider/向量库抽象层，本地 mock 起步。
5. **目录地图同步**：新增 `services/render`（Node 渲染服务），`AGENTS.md` 目录地图需同步。
6. **Agent 副作用护栏**：AI 工具调用凡写库/打印/控制设备，强制 human-in-the-loop 二次确认；工具参数 JSON Schema 强约束；向量检索与工具调用全程带 `tenant_id`。
