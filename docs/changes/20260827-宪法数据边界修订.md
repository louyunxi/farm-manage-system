# 变更提案：宪法数据与边界修订

## 变更类型
修改宪法

## 变更原因
技术栈与需求已定稿（ADR-001、roadmap v0.2），宪法若干处仍停留在起草态：3.2 时间类型写 PostgreSQL 的 `timestamptz` 与 MySQL 选型冲突；2.2 后端仍"待定"；1.2 IoT 边界措辞可能把"第三方 API 级设备控制"误读为越界；术语表仅 6 词，无法覆盖新增需求。

## 变更内容
- 3.2 时间：`timestamptz` → MySQL `DATETIME` 存 UTC。
- 2.2 后端：`待定` → Java / Spring Boot 3.x + JDK 21（指向 ADR-001）。
- 1.2 边界：补注 IoT 硬件直连指 MQTT/Modbus 等协议直连；第三方平台 API 的数据接入与设备控制（API 级指令下发）属允许范围。
- 术语表：补 10 词（种植计划、物联网基地、设备、传感器、农机、合格证、溯源码、物候期、知识库、检测）。
- 版本：升 v1.2。

## 影响范围
- 受影响：`docs/constitution.md`（1.2、2.2、3.2、四、七）。
- 关联：`docs/architecture/ADR-001`（已固化这些决策，宪法本次对齐）。
- 不影响：架构原则、SDD 约束（5.x 已在 v1.1 集成 OpenSpec）。

## 评审结论
通过 + 用户（项目所有者）+ 2026-08-27 + 备注：审计缺口 1 的收口，当场执行。
