# Design: 溯源展示

## Context

公开页无鉴权，只读聚合 02/03/04/06 数据。详见 proposal.md。

## Goals / Non-Goals

**Goals:** 公开溯源页。

**Non-Goals:** 不做溯源数据的防伪/存证（区块链等，留后续）。

## Decisions

### 1. 只读聚合

公开页按 `trace_code` 查 `certificate` → 关联批次 → 聚合地块/农事/检测。通过 service 接口跨模块取数（宪法 2.1）。

### 2. 访问控制与限流

无鉴权公开页加限流（防枚举溯源码）；溯源码高熵（域 06 生成）。

### 3. 部署形态

公开页可作为前端独立路由（`/trace/:code`）或轻量独立应用，SSR/静态优先保证 SEO 与秒开。

## Risks / Trade-offs

- **溯源码枚举** → 高熵码 + 限流。
- **公开页泄露租户内部数据** → 只暴露白名单字段（产地/地块名/农事摘要/检测结论），不泄露成本/人员等敏感字段。
