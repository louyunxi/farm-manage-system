# Proposal: 投入品库存

## Why

农资（农药/化肥/种子）的档案与出入库流水是生产与质量追溯的物资基础。库存需只增不改的流水模型，保证可审计。

## What Changes

- **农资档案**：农资目录/效期管理。
- **入库**：采购/退库入库流水。
- **出库**：领用/调拨出库流水。
- **库存查询**：实时库存与批次效期。

## Capabilities

### New Capabilities

- `input-inventory`: 投入品库存——农资档案、出入库流水、库存查询。

### Modified Capabilities

（无）

## Impact

- **数据**：新增 `input_stock`（库存流水，只增不改）、库存快照视图。
- **依赖**：依赖 08（农资目录）；被 03（投入品预估）、06（检测）引用。
- **规范**：对应 `docs/roadmap.md` 域 05。
